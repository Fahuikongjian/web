## 关于《ASTRA YAO · 星环手记》

《ASTRA YAO · 星环手记》（`astrayao`）是一座立足上海、面向长文阅读与技术实验的个人独立数字唱片与出版空间。网站在视觉上以《绝区零》天琴座歌姬**耀嘉音（Astra Yao）**的舞台美学为灵感——黑曜石丝绒夜幕、炙热天鹅绒红光、香槟金五线谱与 33⅓ RPM 黑胶唱片的优雅节拍；而在工程内核上，它始终坚守克制、纯文本与长久在线的独立出版原则。

在这个信息流不断加速、算法推送愈发喧嚣的时代，我依然相信一个朴素的事实：**属于个人的网页，应当像一张精心压制的典藏黑胶唱片——放上唱盘就能随时回响，安静、诚实、经得起多年后的再次播放。**

因此，你在这个站点上看不到弹窗广告、第三方追踪脚本、依赖境外 CDN 的字体文件，也看不到动辄数兆字节的前端构建产物。每一篇文章都以纯文本 Markdown 写就，通过一套简洁透明的 Python 构建脚本生成静态 HTML，最终部署在自己的云服务器上。

## 关于主理人

你好，我是 `astrayao` 的主理人。日常围绕后端系统架构、工程效率与云基础设施展开工作；在工作之外，则迷恋港风复古黑胶期刊质感、中文网页排版工学以及“十年后依然能直接跑起来”的慢软件哲学。

- **美学取向**：偏爱 *Starloop Velvet & Vinyl* 的复古红黑金层次——在深邃丝绒黑 `#0D0A0C` 的背景上，用香槟金细发丝线勾勒秩序，以天鹅绒绯红 `#E12D4B` 标定焦点，兼顾优雅仪态与夜间长文阅读舒适度。
- **技术主题**：现代中文网络排版、独立博客与数字唱片隐喻、单机云主机运维（Nginx / Caddy / HTTPS / 阿里云 DNS 与 ICP 备案）、零重型依赖构建系统。
- **当前状态**：正在上海打磨 `astrayao` 站点体验与开源出版引擎，并同步推进个人域名的 ICP 备案与华东节点生产上线。

## 网站建造说明（Colophon）

本站从内容层到部署层坚持“可阅读、可审计、零锁死”的建造原则：

1. **内容主权**：所有文章与结构化元数据以 Markdown 和 JSON 存储在本地仓库中，不依赖任何专有数据库或云端 CMS。
2. **渲染引擎**：使用 Python 3.13 标准库配合 `Pygments` 完成静态页面、站内检索索引、RSS 2.0 订阅源与 Sitemap 生成，构建耗时控制在毫秒级。
3. **视觉与字体**：默认呈现 *Starloop Night* 丝绒暗夜主题（同时支持切换至 *Ivory Collector's Edition* 象牙日间典藏版），严格选用离线可用的系统级中文字体栈，保证国内网络环境下首屏瞬时渲染。
4. **运行环境**：全部产物均为纯静态文件，可部署于阿里云华东 2（上海）ECS 上的 Nginx 或 Caddy 2，配合合理的缓存头与安全响应头稳定服务。
