# 《大闰录》全卷实现说明

## 入口与揭露顺序

主站「解密」进入 `/mystery/` 的「旧网拾遗」目录。五卷可分别进入，站点备份和受理记录各自保存。「未完待续」留页包含缺页登记。页首保留导航、检索、地址和随页面可用的历史版本、源码。浏览器前进、后退和复制链接可恢复页面与版本。

| 卷目 | 本案能够证实的内容 | 留给后续的材料 |
| --- | --- | --- |
| 一 · 纸傩代身 | 太平社原底片多出一人，槐安里折返平台确有夹层，无签发的公示改稿试图催拆青砖闷梁。对照原件可先封梁并保留住户的纸本。 | 原片中人的来路、网页异常日期的缘由和半联跨县撕条。 |
| 二 · 门牌余号 | 澄溪 17-乙 原属测绘占位，却被转入正式册。地籍、票据和退信可定位误号，恢复段素兰 17 号的投递，并把余号另册存留。 | 两地留件办法相似，衬页出现同一署名和另半联撕条。 |
| 三 · 借姓簿 | 沿埠沈家的亲签被借住旁注覆盖，用出生、迁居和原声恢复原册。 | 同一署名出现在下一地的原钟校对。 |
| 四 · 失日台 | 鸣川实际观测日被缓存挤掉，用纸带、授时、校签和印历归还首班。 | 异页和多余时刻与蒲岭录音吻合。 |
| 五 · 空炉回香 | 蒲岭原未署的神位被人为抄成代收名位，重新核实修复首件、保全空槽、退回愿纸。 | 五联裁口相合，可到总目录补登缺页。 |
| 大闰总录 | 对照五脉与四柱，复核校历人的来历、太闰的替换次序、正历的阈值及宿主印记。 | 主线在正历保全回执处收束。 |

「名、时、形、祀」是系列设定。卷内使用当地人和机构的词，例如「暂号」「游离页」「双收」。公开入口只给出地方案件的线索，总录和宿主反转各自经过一次核验才出现。

## 资料与核对件

- `static/mystery/data/act-1.json` 有 42 份新增记录，附带丰宁原有的非遗馆、物业、博客、论坛和检索站。11 件核对涵盖末场声音、折返平台、工牌、原片封套、存档日期、改稿、两个钟、寄样、保全、戏箱撤运路径和纸件复录。
- `static/mystery/data/act-2.json` 有 42 份记录，分属清河街道、地籍抄录站、五港渡口、清河通讯和河道保管所。11 件核对涵盖旧牌、地界、折页朝向、渡票、灯号、退信、多出的回单、馆际来件、分册、复递路径和户签墨次。
- 第三至第五幕各有 44 份记录、11 件核对和一份结案回执。总录有 20 份独立资料、6 件会勘和终审。
- 每卷的收件处用 `checks` 生成分件与原件查阅说明，所有分件通过后才受理 `conclusion`。字段可配置等义写法。定向索引条目使用 `index: "site"`，对应的 `listed: false` 使其留在站点目录之外。带 `snapshot` 的记录可通过页首读取原版。
- 卷一延用 `darun_save_v1_ch01` 的馆藏和博客访问状态。卷二使用 `darun_save_v1_ch02`。新回执按卷编号存储，填写中的表单按当前浏览器标签页暂存。

五卷都按首次独立调查 120 分钟以上编排，实际时间受查阅顺序、提示和玩家经验影响。自动化验证入口、资料与谜题流程、回执、存档及隐藏终审。首次游玩时长需由未见答案的玩家实测。
