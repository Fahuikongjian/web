中国古代历法中，太阳回归年与月亮朔望月存在天然误差（气盈朔虚），古人以**“闰月”**强行弥合时间裂缝。但在本世界观中，**“闰”并非计算误差，而是宇宙底层逻辑中一道真实存在的“空隙”**。

* **【时】**：六十甲子与二十四节气构成的严密时间网。
* **【名】**：族谱、户籍、生辰八字与生死簿构成的个体身份锚点。
* **【形】**：堪舆风水、建筑规制（如鲁班尺、门槛、梁柱）构成的物理空间边界。
* **【祀】**：香火、祭仪、禁忌构成的“人与非人”的契约红线。
四柱严丝合缝，则人间太平；一旦在历法流转中出现“多余的时光”、“漏记的名字”、“多出的房间”或“拜错的神位”，这些错位之物便会坠入裂缝，滋养隐藏在一切异常背后的幕后推手。
